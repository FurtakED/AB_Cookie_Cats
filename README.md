# A/B-тест: положение гейта в Cookie Cats

Гейт это уровень, на котором игрока просят подождать или заплатить. Контроль: гейт
на 30-м уровне, тест: на 40-м. Гипотеза продукта - отодвинутый гейт повышает удержание.

**Ноутбук:** смотри в ветке

## Решение

Гейт не переносить.

`retention_7`: 19.02% -> 18.20%, эффект -0.82 п.п., CI95 [-1.33; -0.31] п.п.,
p = 0.0016. Решающее правило требовало прироста не менее +1 п.п., гипотеза
«эффект достигает порога» отвергнута (p = 1e-12), весь интервал ниже нуля.

Оценка смещена. SRM p = 0.0086, на негативном контроле сдвиг того же знака
(-0.59 п.п., p = 0.074). Величину -0.82 п.п. считаем ориентиром, а не измерением.
Знак вывода устойчив, в плюс не ушла ни одна метрика.

## Метрики

| Метрика | Роль |
|---|---|
| `retention_7` | решающая |
| `retention_1` | негативный контроль |
| `sum_gamerounds` | диагностическая |

## Содержание

| Раздел | Что сделано |
|---|---|
| 1 | Загрузка, проверка схемы, пропусков и уникальности `userid` |
| 2 | Роли метрик и решающее правило |
| 3 | Детектируемый эффект при мощности 80%, отдельно по метрикам |
| 4 | Санити-чеки: SRM, A/A на 5000 перестановок, тяжёлый хвост |
| 5 | z-критерий против нуля, односторонний тест против порога +1 п.п., негативный контроль, множественные сравнения |
| 6 | Симуляция ежедневных проверок, раздутие доли ложных срабатываний |
| 7 | Решение |

## Данные

`cookie_cats.csv`, 90 189 игроков. Колонки: `userid`, `version` (`gate_30` / `gate_40`),
`sum_gamerounds`, `retention_1`, `retention_7`.
Источник: [Kaggle, yufengsui/mobile-games-ab-testing](https://www.kaggle.com/datasets/yufengsui/mobile-games-ab-testing).

Даты установки, номера уровня и денежных метрик в датасете нет, объём выборки
зафиксирован.

## Запуск

```bash
pip install numpy pandas scipy statsmodels matplotlib jupyter
jupyter notebook ab_test_cookie_cats.ipynb
```

`cookie_cats.csv` кладётся рядом с ноутбуком. Ноутбук выполняется сверху вниз,
версии библиотек печатает первая ячейка. У каждой случайной процедуры свой
генератор, результат ячейки не зависит от порядка запуска.
